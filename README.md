# 🗺️ 地図クラフト - 3D MapCraft

Three.js で作られた、3Dボクセル世界で日本地図＆世界地図を楽しく学べる学習パズルゲームです！

🌐 **公開URL (GitHub Pages):**  
👉 **[https://hisanoripyon1226-basketball-alt.github.io/eight-app-2/](https://hisanoripyon1226-basketball-alt.github.io/eight-app-2/)**

---

## ✨ 特徴・主な機能

1. **🧱 3Dボクセルクラフトワールド (Three.js)**
   - 3D空間に浮かぶボクセルの世界！海、雲、立方体ブロックで形作られる日本列島と世界大陸。
   - 正解すると、上空からブロックがドスン！と落下しカチッと組み上がる爽快なクラフトアニメーション。
   - ブロックの上には、富士山やエッフェル塔、お城、ビル、木々などのかわいい立体ミニチュアがポンッと出現！

2. **🗾 日本地図モード（47都道府県 完全収録）**
   - **地方別プレイ:**
     - 北海道・東北地方
     - 関東地方
     - 中部地方
     - 近畿地方
     - 中国地方
     - 四国地方
     - 九州・沖縄地方
     - 全日本チャレンジモード

3. **🌍 世界地図モード（6大州・主要国 収録）**
   - **大陸別プレイ:**
     - アジア大陸
     - ヨーロッパ大陸
     - 北アメリカ大陸
     - 南アメリカ大陸
     - アフリカ大陸
     - オセアニア
     - 全世界チャレンジモード

4. **💡 充実のヒント＆クラフトステーション**
   - 地図上の未配置スロット（「？」ブロック）をクリックすると、カメラがズーム！
     - 🏛️ **首都 / 県庁所在地**
     - 🍎 **代表的な名物・特産品**（アイコン付き）
     - 🏯 **有名な名所・世界遺産**
     - 💡 **豆知識・地理トリビア**
   - 3択のクラフトボタンから正解を選ぶことで、楽しく確実に暗記・学習できます。

5. **🎒 手持ちインベントリ（ホットバー）**
   - 画面下部に配置可能なピースが一覧表示され、直接選んで地図にカチッとはめ込むことも可能。

6. **📖 クラフト完成ずかん（図鑑）機能**
   - 配置済みのブロックをクリックすると、いつでもその都道府県や国の詳細データと雑学をじっくり鑑賞できます。

7. **🎵 Web Audio API 完全内蔵サウンド**
   - 外部音声ファイル不要！クラフト時の「カチッ」「ガコン」、正解チャイム、ファンファーレ、8bit風チップチューンBGMをリアルタイム合成再生（ミュート切り替え可能）。

8. **📛 ふりがな（ルビ）トグル機能**
   - 小学生やお子様でも一人で学習できるよう、すべての漢字にふりがな付き（ON/OFF切り替え可能）。

9. **⏱️ タイムアタック＆スター評価（★1〜3）**
   - クリアタイムとヒント使用回数に応じてクラフトマスター評価！

---

## 🎮 操作方法

- **地図の回転:** マウス左ボタンドラッグ / 指1本スワイプ
- **地図の移動（パン）:** マウス右ボタンドラッグ / 指2本スワイプ
- **ズームイン・アウト:** マウスホイール / ピンチイン・アウト
- **視点リセット:** 画面右上の「🎥 視点リセット」ボタンでいつでも全体表示に戻せます。
